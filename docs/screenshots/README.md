Capture a window with ⌘⇧4, then Space, then click the window. Use non-copyrighted clips and photos
(your own, or Blender's open movies such as Big Buck Bunny), and check thumbnails and file names for
anything personal before uploading. The Images tab shows locations as coordinates.

After adding `images.png`, remove the `<!--` and `-->` lines around it in the main README.
